## Installation 🛠️

Install packages using pnpm:

```bash
# Install the core logger
pnpm add @feizk/logger

# Install the Discord transport plugin
pnpm add @feizk/logger-discord
```

Or install both together:

```bash
pnpm add @feizk/logger @feizk/logger-discord
```
